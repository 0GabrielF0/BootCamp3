# Validador de Placas Brasileiras

Projeto desenvolvido para validação de placas de veículos brasileiros, considerando os padrões **antigo** e **Mercosul**.

## Objetivo

Desenvolver um modelo capaz de identificar se uma placa informada é **válida ou inválida**, de acordo com as regras dos padrões definidos para o projeto.

## Tecnologias

* Python
* FastAPI
* pytest
* Docker
* Git e GitHub

## Estrutura

O projeto será organizado em:

* `app/` — código da aplicação
* `tests/` — testes automatizados
* `specs/` — especificações do projeto
* `docs/` — documentação
* `AGENTS.md` — instruções para o agente de IA

## Desenvolvimento

O projeto seguirá **Spec-Driven Development (SDD)**, utilizando as especificações como base para a implementação e os testes.
